# Complex Tori, Jacobians, and Elliptic Curves

This is an independent LaTeX textbook project on complex tori, Jacobians, and
elliptic curves.

The project is intentionally separate from `../book/`.  It may read shared
generated figure coordinates from `../sagemath/` and local TikZ figure sources,
but it does not modify those sources.

Build from this directory:

```sh
pdflatex main.tex
pdflatex main.tex
```

The first edition is a compact textbook draft: each chapter contains narrative
exposition, definitions or theorem statements, exercises, and pointers to full
solutions in the appendices.
